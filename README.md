# swift-spr-renovate-demo

A minimal Swift package that resolves its dependencies through a **Swift
Package Registry** (SE-0292) instead of the classic SCM `git clone`
flow, used as a real-world test bed for adding SE-0292 support to
[Renovate](https://github.com/renovatebot/renovate).

## What's in this repo

- **`Package.swift`** declares two dependencies via SE-0292 identity
  form (`.package(id: "scope.name", ...)`) instead of URL form:
  - `apple.swift-argument-parser`
  - `apple.swift-log`
- **`.swiftpm/configuration/registries.json`** points SwiftPM at
  the open [Tuist Registry](https://tuist.dev/blog/2025/11/26/opening-registry)
  at `https://tuist.dev/api/registry/swift`, which mirrors popular
  Swift packages with no authentication required.
- **`Package.resolved`** is generated by `swift package resolve` and
  pins each dep using SE-0292's `"kind": "registry"` pin shape — the
  same shape Renovate must learn to update.

## Why

[SE-0292](https://github.com/swiftlang/swift-evolution/blob/main/proposals/0292-package-registry.md)
introduced an HTTP package-registry protocol for SwiftPM. Adoption is
growing — Apple's preview registry, Tuist's public registry, and
several private/enterprise registry servers all speak the protocol —
but Renovate's `swift` manager only parses `.package(url:)` SCM
references. It doesn't recognize `.package(id:)`, has no datasource
that speaks the SE-0292 list-versions endpoint, and doesn't know how
to update `kind: "registry"` pins in `Package.resolved`.

This repo is the integration target for that feature work upstream.

## Reproduce locally

```bash
git clone https://github.com/bdolewski/swift-spr-renovate-demo
cd swift-spr-renovate-demo
swift build
swift run Demo "your name"
# → "info demo: [Demo] Hello, your name!"
```

`swift package resolve` will hit `https://tuist.dev/api/registry/swift`
and resolve both deps from the Tuist mirror. No authentication needed.

## Trigger a Renovate bump PR

To watch Renovate detect an outdated registry-form dep and PR a bump
(once upstream SE-0292 support ships), downgrade the pinned versions
locally before running Renovate against the repo:

```bash
# Edit Package.resolved — drop version numbers to older releases, e.g.:
#   "apple.swift-argument-parser" -> "1.0.0"
#   "apple.swift-log"             -> "1.4.0"
# Save, commit, push, then let Renovate scan the repo.
```

Renovate will see that `apple.swift-argument-parser@1.0.0` is older
than the latest version returned by the registry's
`/apple/swift-argument-parser` endpoint and open a PR updating both
`Package.swift` (the `from:` constraint) and `Package.resolved`
(the `state.version` field on the `kind: "registry"` pin).
